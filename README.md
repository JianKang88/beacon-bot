# 灯塔自动化 v1.0

**无需安装Python，双击即可运行**

## 使用步骤

### 方式一：直接下载exe（推荐）

1. 从Release页面下载 `灯塔自动化-v1.0.zip`
2. 解压到任意文件夹
3. 双击 `灯塔自动化.exe` 运行
4. 确保游戏已打开在大世界出生点

### 方式二：自己打包exe

如果你已经有Python环境，可以自己打包：

```bash
# 1. 安装依赖
pip install -r requirements.txt
pip install pyinstaller

# 2. 提取模板图片
python extract_templates.py 灯塔需求.docx

# 3. 打包exe
python build_exe.py

# 4. 打包完成后，exe在 dist/ 目录
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `灯塔自动化.exe` | 主程序（双击运行） |
| `templates/` | 怪物模板图片目录 |
| `config.json` | 配置文件（运行后自动生成） |

## 首次运行

1. 打开游戏，进入**大世界出生点**
2. 运行 `灯塔自动化.exe`
3. 程序会自动：
   - 启动浏览器
   - 导航到游戏页面
   - 开始自动化流程

## 快捷键

- `Ctrl+C` 或关闭窗口：停止自动化

## 注意事项

1. **分辨率**：默认1920x1080，如果不是请修改config.json
2. **OKX钱包**：首次运行需要手动登录钱包，之后会自动保存登录状态
3. **游戏窗口**：确保游戏窗口不被其他窗口遮挡

## 问题排查

**Q: 提示找不到模板图片？**
A: 确保 `templates/` 文件夹和exe在同一目录

**Q: 怪物识别不准确？**
A: 可以替换 `templates/` 里的图片为你自己截的怪物图

**Q: 坐标不对？**
A: 修改生成的 `config.json` 文件调整坐标
